OpenAI 暫停開發超強新模型 Astra，主因網路安全潛在風險

Microsoft Edge 跟進 Chrome 政策，將阻擋舊版廣告攔截器

Microsoft Edge 瀏覽器宣布將終止支援 Manifest V2 擴充功能平台，此舉將導致 uBlock Origin 等舊版廣告阻擋器無法使用。這與 Google Chrome 先前採取的政策一致。微軟表示，目前 Edge 擴充功能商店中，僅有極少數具實際用量的擴充功能仍使用 MV2，且其中大部分已有更新的 MV3 版本。受影響的使用者可改用如 uBlock Origin Lite 或考慮支援 MV2 的 Opera 瀏覽器。

波蘭政府網站資安驚爆危機：法院、醫院、機場曝露駭客風險
